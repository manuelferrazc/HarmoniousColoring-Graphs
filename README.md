# Harmonious Coloring - Input Graphs
This repository contains the graphs that were used as input in the article "A Branch and Cut to Harmonious Coloring", along with the program used to create these graphs

The graphs are in the directory **graphs/**, divided into four sets: RAND1, RAND2, RAND3 and RAND4.

Within each set there are 30 distinct graphs: 6 graphs for each size (number of vertices): 10, 20, 30, 40 and 50.

Each graph has its density (the ratio of the number of edges of the graph and the number of edges in the complete graph of the same size). The avaliable densities for each size of the graphs are 0.01, 0.03, 0.05, 0.1, 0.2 and 0.3.

The name of the files explains the information of the graphs. 

Graphs with the same name have the same number of vertices and edges. What changes is which edges were created.

The graphs were randomly generated by the program **gen.py**.
